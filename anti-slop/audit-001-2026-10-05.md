# Tailcat 1.21.11 메뉴 UI 감사

- 모드: AFTER, 세션 지정
- 범위: Fabric, Forge, NeoForge의 멀티플레이 화면 Tailcat 연결 버튼 재초기화 및 배치 로직
- 방식: 코드 정적 검토
- 실행 검증: 창 크기 변경을 통한 인게임 재현은 하지 않았습니다.
- 코드 변경: 하지 않았습니다.

## Findings

### 1. [HIGH] 높이를 줄이면 기존 연결 버튼이 화면 밖에 남을 수 있습니다

- 규칙: R-03 반응형 레이아웃, R-26 동작 가능한 인터랙션
- 위치:
  - `mod-fabric-1.21.11/src/main/java/com/tailscale/mclink/McLinkClient.java:66`
  - `mod-forge-1.21.11/src/main/java/com/tailscale/mclink/McLinkClient.java:89`
  - `mod-neoforge-1.21.11/src/main/java/com/tailscale/mclink/McLinkClient.java:98`
- 근거: 화면이 재초기화될 때 기존 버튼의 Y 좌표가 유지되고 바닐라 버튼이 새 화면 높이 기준으로 다시 배치되면, 높이 축소 시 기존 버튼 Y가 새 `row3Y`보다 커질 수 있습니다. 현재 조건은 그 경우 레이아웃 보정과 Y 좌표 갱신을 생략합니다.
- 영향: 화면이 충분히 작아지면 Tailcat 연결 버튼이 하단 뷰포트 밖에 남아 선택할 수 없게 됩니다.
- 개선 방향: 기존 버튼 위치의 대소 비교만으로 보정 여부를 정하지 말고, 현재 화면 크기와 바닐라 버튼 배치에서 목표 좌표를 다시 산출해 버튼 위치를 매번 현재 레이아웃에 맞추십시오.

### 2. [HIGH] 폭 변경 시 기존 연결 버튼의 X 좌표가 갱신되지 않습니다

- 규칙: R-03 반응형 레이아웃, R-26 동작 가능한 인터랙션
- 위치:
  - `mod-fabric-1.21.11/src/main/java/com/tailscale/mclink/McLinkClient.java:81-84`
  - `mod-forge-1.21.11/src/main/java/com/tailscale/mclink/McLinkClient.java:107-110`
  - `mod-neoforge-1.21.11/src/main/java/com/tailscale/mclink/McLinkClient.java:116-118`
- 근거: 버튼의 중앙 정렬 X 좌표는 새 버튼을 만들 때만 계산됩니다. 기존 버튼을 찾은 재초기화 경로에서는 X 좌표와 폭을 현재 `width`에 맞춰 갱신하지 않습니다.
- 영향: 넓은 창에서 좁은 창으로 바꾸면 버튼이 이전 위치에 남아 중앙 정렬이 깨지고, 축소 폭에 따라 일부 또는 전체가 화면 밖으로 벗어날 수 있습니다.
- 개선 방향: 재초기화 때 기존 버튼에도 현재 너비 기준의 목표 X 좌표와 크기를 적용하십시오.
